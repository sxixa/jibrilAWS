Shared Hosting Dedicated Server Amazon Lightsail Amazon EC2 (Elastic Compute Cloud)
Layanan hosting di mana satu server fisik beserta sumber dayanya (CPU, RAM, penyimpanan) dibagi bersama dengan banyak pengguna/website lain. Biayanya murah dan mudah dikelola, tetapi performa bisa terdampak oleh trafik website lain dan akses konfigurasinya terbatas. Layanan hosting di mana satu server fisik disediakan secara eksklusif untuk satu pengguna/website. Biayanya lebih mahal tetapi performa dan kontrol yang diberikan lebih baik. Layanan cloud yang menyediakan server virtual dengan spesifikasi tertentu, mudah digunakan dan cocok untuk website kecil hingga menengah. Layanan cloud yang menyediakan fleksibilitas dan kontrol penuh terhadap sumber daya komputasi, cocok untuk aplikasi yang memerlukan skalabilitas tinggi.
